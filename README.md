# SimpliciTees-Official-Site

A responsive e-commerce website mockup for SimpliciTees, a T-shirt brand developed as part of the MMS 142 course project.

## About the Project

This website serves as the primary sales channel for the client’s T-shirt line. The website helps the startup build brand awareness and showcase product quality. A professionally designed site will also give first-time buyers a reason to trust the brand.

## Project Features

- Responsive and mobile-friendly design
- Accessible and Inclusive Design (AID) principles
- Custom T-shirt product showcases
- Contact form for customer inquiries
- Email-based ordering functionality
- Built using HTML, CSS, JS, and Bootstrap
